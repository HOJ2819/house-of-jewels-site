================================

Files:
- index.html       Main responsive website
- styles.css       Styling and mobile layout
- script.js        Small navigation/year script
- privacy.html     Starter privacy notice

PREVIEW
Open index.html in a modern browser.

PUBLISH FOR FREE
One straightforward option is GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository (for example: house-of-jewels-site).
3. Upload index.html, styles.css, script.js and privacy.html to the repository root.
4. In repository Settings -> Pages, choose deployment from the main branch and root folder.
5. Wait for GitHub Pages to publish and copy the exact HTTPS URL it provides.
6. Open the published URL on desktop and mobile and test every link.

A free host may provide a subdomain such as username.github.io/house-of-jewels-site/.
You do not need to buy a domain for this first version.
